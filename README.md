# HMBot Benchmark Dashboard

[打开 Cofi Android → HarmonyOS 实验计划](experiments/cofi-android-harmony.md)

独立页面：`experiments/cofi-android-harmony.html`，含 11 组实验、状态筛选及历史结果镜像登记。HTML 可直接打开，也可使用任意静态服务托管。

数据源：`data/cofi-android-harmony.json`。更新数据后运行 `python3 scripts/render.py` 同步生成 HTML 和 GitHub 文档版。当前仅登记计划和历史证据，不自动发起实验。

六组历史迁移自报完成不代表独立验收通过；本地 Tart 克隆名称不等于远程下载地址。尚未配置 GitHub Pages。
